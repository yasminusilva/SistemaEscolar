# Agiliza — Sistema de Gestão Acadêmica

O **Agiliza** é um sistema web de gestão acadêmica desenvolvido para facilitar o acesso e o gerenciamento de informações escolares.

O projeto possui áreas específicas para alunos e professores, permitindo consultar informações acadêmicas e realizar tarefas relacionadas à rotina escolar.

## Funcionalidades

### Cadastro e Login
- Cadastro de novos usuários
- Login de alunos e professores
- Seleção do tipo de usuário
- Cadastro de turma para alunos

### Área do Aluno
- Visualização dos dados pessoais
- Visualização da turma
- Consulta de disciplinas com notas lançadas
- Consulta de notas
- Visualização da frequência
- Visualização das próximas atividades

### Área do Professor
- Cadastro de alunos
- Seleção de turmas
- Lançamento de notas
- Registro de frequência
- Visualização dos alunos cadastrados
- Consulta de notas e frequência
- Visualização de turmas e avisos

### Tecnologias utilizadas

 - HTML

 - CSS

 - JavaScript

### Interface

As páginas principais são:

 - Login/Cadastro

 - Área do Aluno

 - Área do Professor
